# research/ — RFG 엔진 v2 백테스트

`src/core` 의 엔진(v1 → v2)을 정한 연구 기록이다. 여기서 정한 값이 `src/core/constants.ts` 로 들어갔고,
TS 엔진과 이 코드의 값이 소수 6자리까지 같음을 확인했다(`r01_parity.py`, 2026-10-13 SPX·NDX 스냅샷 대조).

## 1. 목표 — 지수로서 정확한가

이 앱은 매수·매도 신호가 아니라 CNN 공포·탐욕 지수처럼 **지금 시장이 얼마나 무서운가를 0~100 으로 보여주는 지수**다.
그래서 엔진을 "이후 수익률을 맞히는가"가 아니라 **"실제로 일어난 일을 제때 정확히 보여주는가"** 로 골랐다.

| 기준 | 정의 | 좋은 방향 |
|---|---|---|
| 정확도 (AUC) | 공포 정답일을 탐욕 정답일보다 낮게 매길 확률 | 1 에 가까울수록 |
| 공포일·탐욕일 중앙값 | 정답일에 지수가 실제로 보인 값 | 공포일은 낮게, 탐욕일은 높게 |
| VIX 일치 | 옵션 시장 공포(VIX)와의 순위상관(지수가 낮을 때 VIX 가 높다) | 클수록 |
| CNN 상관 | 대중 심리와의 상관 | 0.8 이상 유지 |
| 하루 변동 | 하루 평균 \|변화\| | CNN(3.2) 이하 |

**정답지** (`r10_index_quality.py` 의 `truth_labels`)

- 공포 정답일: 1년 고점 대비 −10% 이상 빠진 바닥(앞뒤 3개월 안 최저 종가) ±5일, 그리고 바닥 ±21일 안에서 바닥 낙폭의 85% 이상 빠져 있던 날
- 탐욕 정답일: 1년 고점 대비 −3% 이내이면서 63거래일 수익률이 플러스인 날 — 급락 뒤 회복한 날도 들어가므로, 반등 뒤에도 공포에 머무는 지수는 감점된다

정답지가 가격으로 만들어져서 가격 지표에 유리한 순환이 생긴다. 그래서 가격과 독립인 **VIX** 와 **CNN** 을 함께 본다.

## 4. 발견

1. **v1 은 지수로서 나쁘지 않았지만 출렁였다.** 정확도 0.91–0.96 으로 CNN 단독(0.88–0.92)보다 높았으나 하루 변동이 4.4–5.9 로 CNN(3.2)보다 컸고, ≤20·≥80 에 머무는 날이 11–18% 로 너무 잦았다.
2. **가격 쪽은 '1년 고점 대비 낙폭'과 '200일선 이격도'를 5년 기준으로 볼 때 가장 정확했다.** 세 장기 시장(나스닥 종합 50년·닛케이 66년·나스닥100)의 순위가 거의 같았다(순위상관 0.96–0.98).
   짧은 창(60일·50일)은 조정 중 반등에 공포가 너무 빨리 풀렸고, 1년 백분위 창은 긴 약세장에서 기준이 같이 내려가 공포를 덜 보였다.
3. **성분은 각각 백분위로 바꾼 뒤 섞어야 했다.** 원시값을 먼저 합치면 연율 변동성처럼 크기가 큰 성분이 지배한다.
4. **심리 가중치 0.3–0.6, 평활 1–5일이 모두 정확도 0.99 근처인 평탄한 영역이었다.** 그 안에서 CNN 상관 ≥ 0.8, 하루 변동 ≤ CNN 을 지키는 0.6 / 3일을 골랐다.

## 5. 채택한 v2

```
P_t   = 0.5·pct(−DD252)_t + 0.3·pct(−DISP200)_t + 0.2·pct(RV20)_t      각 pct 는 1260일(약 5년) 롤링 백분위
RFG_t = EMA3[ 0.6·FG_t + 0.4·(100 − P_t) ]                              EMA α = 0.5, 구간 판정·화면은 이 값
```

| | v1 | v2 |
|---|---|---|
| 낙폭 창 / 이동평균 창 / 변동성 창 | 60 / 50 / 20 | 252 (1년 고점) / 200 (200일선) / 20 |
| 백분위 창 | 252 | 1260 |
| P 합성 | 원시값 합성 후 백분위 | 성분별 백분위의 가중 평균 |
| 가중치 α/β/γ | 0.5/0.3/0.2 | 같음 |
| 심리/가격 | 0.4/0.6 | 0.6/0.4 |
| 평활 | 없음 | 3일 EMA |

구간 문턱(≤20 실질적 항복, ≥80 실질적 과열)과 사분면·FRM 문턱은 그대로다. 최소 종가는 311 → 1511(스냅샷 1570) — FRED 10년(약 2,500개)으로 충분하다.

## 7. 한계

- 정답지는 "1년 고점 대비 −10% 바닥 = 공포, 고점 부근 상승 = 탐욕"이라는 하나의 정의다. 다른 정의(예: −20%, 6개월 고점)를 쓰면 숫자는 달라진다. 순환을 줄이려고 VIX·CNN 을 같이 봤다.
- v2 는 극단값(≤20, ≥80)이 v1 보다 드물다(CNN 과 비슷한 수준). 2026 봄 조정처럼 CNN 이 극단 공포(8)여도 가격 훼손이 크지 않으면 v2 는 20 근처에 머문다 — "실질" 지수의 의도된 성질이다.
- 장기 구간의 심리는 근사치(SFG, CNN 과 상관 0.82)다. 실제 CNN 으로 검증한 건 2020-07 이후다.
- S&P 500 장기 일별 데이터를 구하지 못해 장기 검증은 나스닥·닛케이로 대신했다.

## 8. 기각한 접근 — 예측력 기준 (`r03`–`r09`)

처음에는 "지수가 낮으면 이후 수익률이 높은가"(역발상 IC, 구간 수익률)로 골랐다. 그렇게 고른 엔진(60일 변동성 중심 P, 3년 백분위, 기하 결합)은
수익률 예측은 v1 보다 조금 나았지만 지수로서는 나빴다 — 반등 뒤에도 공포에 머물렀고(2025-05-30 CNN 62 / 그 엔진 33),
10% 조정을 놓쳤으며(2023-10-27 CNN 22 / 53), CNN 상관이 0.55 로 떨어졌다. 이 앱의 목적(지수 표시)과 맞지 않아 기각했다.
그 과정의 표는 `out/rejected_predictive_tables.md`, 스크립트는 `r03_grid_price.py`–`r09_final.py` 에 남겨 둔다.
